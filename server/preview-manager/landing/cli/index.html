Preview CLI

Command-line tool for managing preview environments. Supports Linux and macOS (amd64/arm64).

Installation

One-line install

curl -fsSL https://api.druploy.dev/api/cli/install.sh | sh

Downloads the binary to ~/.local/bin/druploy. Make sure ~/.local/bin is in your PATH.

Quick Start

Get up and running

druploy setup api https://api.druploy.dev
druploy login
druploy list
